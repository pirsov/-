# Подготовка к зачёту «Основы российской государственности» — 3 дня

## Как пользоваться

- Каждый день: **теория (4–5 ч) → самопроверка (1 ч) → повтор сложных тем (1 ч)**.
- Ответ на зачёте: **определение → 3–5 тезисов → пример / вывод** (2–3 минуты устно).
- Жирным в конспектах отмечены формулировки, которые стоит запомнить дословно.
