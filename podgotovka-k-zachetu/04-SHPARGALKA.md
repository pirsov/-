# Шпаргалка накануне зачёта (15–20 минут на блок)

## Блок A. Государство и цивилизация

**Государство** = территория + народ + суверенная власть + право + аппарат.  
**Государственность** = историческая способность народа иметь и развивать государство.  
**Этапы:** Киевская Русь → раздробленность/Москва → царство → империя → СССР → РФ.  
**Государство-цивилизация** = политическое единство на базе культурно-исторической общности многих народов.  
**Государство-нация** = единство прежде всего через гражданскую нацию.  
**Принципы РФ:** суверенитет, целостность, народовластие, федерализм, правовое/социальное/светское государство, разделение властей, права человека, многонациональность.

## Блок B. Мировоззрение и ценности

**Уровни мировоззрения:** мироощущение → мировосприятие → миропонимание.  
**Ценности РФ:** жизнь, достоинство, патриотизм, семья, труд, справедливость, милосердие, историческая память, единство народов, приоритет духовного.  
**Идеология:** система идей; функции — познание, оценка, ориентация, мобилизация, интеграция, легитимация.  
**Общенациональная идея:** суверенная справедливая Россия-цивилизация для человека и народа.  
**Дилемма:** индивидуализм ↔ традиционализм/солидарность.

## Блок C. Конституция и власть

**Ст. 1:** демократическое федеративное правовое государство, республика.  
**Ст. 2:** человек — высшая ценность.  
**Ст. 3:** народ — источник власти.  
**Ст. 10:** разделение властей.  
**Ст. 12:** МСУ самостоятельно, не в системе госорганов.  
**Форма:** республика + федерация.  
**Легитимность (Вебер):** традиция / харизма / закон.  
**Аристотель:** монархия–тирания; аристократия–олигархия; полития–«демократия» (искаж.).

## Блок E. Россия сегодня и будущее

**Ресурсы:** сила (богатство) и риск (зависимость).  
**Демография:** неравномерность, старение, поддержка семьи.  
**Ростовская обл.:** АПК + промышленность + порт/логистика + южный форпост + казачья культура.  
**Стратегия:** прогнозы → стратегии → госпрограммы → нацпроекты.  
**Нацпроекты:** приоритеты с KPI (демография, здоровье, образование, жильё, дороги, цифра, экология…).  
**Глобализация** = процесс связей; **глобализм** = идеология универсализма.  
**Будущее РФ:** суверенитет + справедливость + технологии + сохранение цивилизационного кода.  
**Мир:** многополярность.
