# ОРГ — подготовка к зачёту

Интерактивный сайт + конспекты по курсу **«Основы российской государственности»**.

## Сайт (мини-игры)

Открой папку [`web/`](web/):

```bash
cd web && python3 -m http.server 8080
```

Затем перейди на http://localhost:8080

### Что внутри
- План на **3 дня** с прогрессом
- Краткие **темы** по вопросам зачёта
- Мини-игры: карточки, викторина, сопоставление, хронология, схема власти
- **Пробный зачёт** на 15 вопросов
- XP и прогресс в `localStorage`

Вдохновлено структурой образовательных материалов о российском государстве-цивилизации.

## Конспекты

Папка [`podgotovka-k-zachetu/`](podgotovka-k-zachetu/) — текстовые материалы на 3 дня.
